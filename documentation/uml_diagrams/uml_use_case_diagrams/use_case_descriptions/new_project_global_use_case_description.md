Кратак опис: Корисник прави нови пројекат из главног менија апликације. Апликација учитава таблу (whiteboard) помоћу које корисник врши уређивање UML дијаграма класа (додавање и брисање чворова и веза). Након што је завршио рад, корисник има могућност да генерише структуриран пројекат у програмском језику C++ притиском на дугме „Generate Code“.

* Актери:
    * Корисник – креира нови дијаграм

* Предуслови: Апликација је покренута и приказује главни мени.

* Постуслови: Кориснички направљен дијаграм је у сваком тренутку валидан.

* Основни ток:
1. Корисник бира опцију „New Project“ и именује пројекат.
2. Корисник интерактивно креира дијаграм (Drag & Drop), при чему се приликом сваког покушаја повезивања врши провера исправности (валидација) дијаграма (да ли је повезивање смислено, да ли постоји дијамант и слично):
    
    2.1. Уколико је дијаграм исправан, прелази се на корак 3.
    
    2.2. Уколико дијаграм није исправан, апликација обавештава корисника путем прозора да је повезивање које је покушао неисправно. Након што корисник кликне „OK“, прелази се на корак 2.
3. Корисник има две опције (описане у наредним подописима):
    
    3.1. Чување дијаграма:
        `export_diagram_use_case_description.md`
    
    3.2. Генерисање пројекта према направљеном дијаграму:
        `generate_project_use_case_description.md`
4. Отварање генерисаног пројекта:
    `modify_project_use_case_description.md`
5. Одабиром опције „Close Project“ затвара се тренутни пројекат и апликација приказује главни мени.

* Алтернативни токови:
    * А1: Неочекивани излаз из апликације. Уколико у било ком кораку корисник искључи апликацију, све евентуално запамћене информације о актуелном пројекту се поништавају и апликација завршава рад. Случај употребе се завршава.
