# Кратак опис: Корисник отвара већ постојећи пројекат из главног менија апликације. Апликација учитава таблу (whiteboard) помоћу које корисник врши уређивање UML дијаграма класа (додавање/брисање чворова/веза). Након што је завршио, корисник има могућност да генерише структуиран пројекат у програмском језику C++ притиском на дугме “Generate code”.
* Актери: 
	- Корисник - уређује учитан дијаграм 
* Предуслови: Апликација је покренута и приказује главни мени.
* Постуслови: Кориснички направљен дијаграм је у сваком тренутку валидан.
* Основни ток:
1. Корисник бира опцију “Import Project” из главног менија:
	1.2.1.  Апликација приказује садржај директоријума на корисниковом рачунару где су складиштени претходно направљени пројекти од стране корисника.
	1.2.2.  Корисник бира жељени пројекат из директоријума.
2. Корисник врши интерактивно уређивање дијаграма (Drag & Drop), при чему се приликом сваког покушаја повезивања врши провера исправности (валидација) дијаграма (да ли је повезивање смислено, да ли постоји дијамант…):
	2.1. Уколико је дијаграм исправан, прелази се на корак 3.
	2.2. Уколико дијаграм није исправан, апликација обавештава корисника путем прозора да је повезивање које је покушао неисправно. Након што корисник кликне “OK”, прелази се на корак 2.
3. Корисник има две опције (описане у следећим подописима): 
    3.1 Чување дијаграма:
        `save_diagram_use_case_description.md`
    3.1 Генерисање пројекта према направљеном дијаграму:
        `generate_project_use_case_description.md`
4. Отварање генерисаног пројекта: `modify_project_use_case_description.md`
5. Одабиром опције “Close Project” затвара се тренутни пројекат и апликација приказује главни мени.
Алтернативни токови:
- А1: Неочекивани излаз из апликациjе. Уколико у било коjем кораку
корисник искључи апликациjу, све евентуално запамћене информаци-
jе о актуелном пројекту се поништавају и апликациjа завршава рад.
Случаj употребе се завршава.
