Кратак опис: Корисник отвара већ постојећи пројекат из главног менија апликације. Апликација учитава таблу (whiteboard) помоћу које корисник врши уређивање UML дијаграма класа (додавање и брисање чворова и веза). Након завршетка рада, корисник има могућност да генерише структуриран пројекат у програмском језику C++ притиском на дугме "Generate Code".

* Актери:
    * Корисник – уређује учитан дијаграм

* Предуслови: Апликација је покренута и приказује главни мени.

* Постуслови: Кориснички направљен дијаграм је у сваком тренутку валидан.

* Основни ток:
1. Корисник бира опцију "Import Project" из главног менија.
2. Апликација приказује садржај директоријума на корисниковом рачунару у ком су смештени претходно направљени пројекти.
3. Корисник бира жељени пројекат из директоријума.
4. Корисник интерактивно уређује дијаграм (Drag & Drop), при чему се приликом сваког покушаја повезивања врши провера исправности (валидација) дијаграма (да ли је повезивање смислено, да ли постоји дијамант и слично):
    
	4.1. Уколико је дијаграм исправан, прелази се на корак 5.
    
	4.2. Уколико дијаграм није исправан, апликација обавештава корисника путем прозора да је повезивање које је покушао неисправно. Након што корисник кликне "OK", прелази се на корак 4.
5. Корисник има две опције (описане у наредним подописима):
    
	5.1. Чување дијаграма:
        `export_diagram_use_case_description.md`
    
	5.2. Генерисање пројекта према направљеном дијаграму:
        `generate_project_use_case_description.md`
6. Отварање генерисаног пројекта:
    `modify_project_use_case_description.md`
7. Одабиром опције "Close Project" затвара се тренутни пројекат и апликација приказује главни мени.

* Алтернативни токови:
    * А1: Неочекивани излаз из апликације. Уколико у било ком кораку корисник искључи апликацију, све евентуално запамћене информације о актуелном пројекту се поништавају и апликација завршава рад. Случај употребе се завршава.
