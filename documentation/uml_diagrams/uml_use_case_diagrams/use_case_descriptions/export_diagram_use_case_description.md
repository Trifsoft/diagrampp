Кратак опис: Корисник чува креирани дијаграм у JSON или PNG формату.
* Актери:
    * Корисник - чува креирани дијаграм
* Предуслови: Креирани дијаграм је валидан.
* Постуслови: Кориснички направљен дијаграм је успешно сачуван.
* Основни ток:
1. Корисник бира опцију “Export Project”.
2. Корисник има две опције:
	2.1. Корисник чува дијаграм у JSON формату.
	2.2. Корисник чува дијаграм у PNG формату.
3. Након одабира формата, кориснику се отвара прозор где бира име фајла и директоријум у ком жели да сачува пројекат. Корисник има две опције:
	3.1. Одабиром опције “Save” корисник чува дијаграм на свом рачунару у жељеном директоријуму под жељеним именом.
	3.2. Одабиром опције “Cancel” корисник је одустао од чувања дијаграма.
4. Кориснику се поново приказује whiteboard.

* А1: Неочекивани излаз из апликациjе. Уколико у било коjем кораку корисник искључи апликациjу, све евентуално запамћене информациjе о актуелном пројекту се поништавају и апликациjа завршава рад. Случаj употребе се завршава.
