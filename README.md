# Diagram++

Diagram++ je alat za vizuelizaciju C++ klasa i njihovih međusobnih odnosa. Projekat omogućava pregled i kreiranje klasa, njihovih metoda, polja, konstruktora, kao i hijerarhije nasledjivanja kroz interaktivni grafički prikaz. Cilj je olakšati razumevanje strukture programa, analiziranje arhitekture i praćenje OOP odnosa u C++ projektima na intuitivan i vizualno pregledan način.
